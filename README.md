# Frontend Mentor - Blog Preview Card

## Preview

![Blog Preview Card](./preview.jpg)

A responsive blog preview card built as a solution to the [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## Live Demo

[View Live Site](ССЫЛКА)

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Google Fonts

## Features

- Responsive layout for desktop and mobile screens
- Semantic HTML structure
- Hover state for the article title
- Custom typography using Figtree
- CSS variables
- Flexbox and CSS Grid for layout

## What I Learned

While building this project, I practiced:

- Semantic HTML
- Flexbox alignment
- CSS Grid
- Responsive design with media queries
- Understanding `align-items` and `stretch`
- Using `max-width` and container padding
- CSS variables
- Working with custom fonts
- Appropriate use of `alt` text
